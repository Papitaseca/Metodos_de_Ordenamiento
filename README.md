# Métodos de Ordenamiento

Este proyecto contiene implementaciones de **Quicksort** y **Shellsort** en Java.

## Requisitos
- Java JDK instalado (incluye `javac` y `java`).

## Clonar el repositorio
```bash
git clone <URL-del-repositorio>
cd <carpeta-del-repositorio>
```

## Compilar
Desde la carpeta raíz del proyecto, ejecuta:
```bash
mkdir -p out
javac -d out src/*.java
```

## Ejecutar
Ejecuta el programa que quieras probar:

```bash
java -cp out Metodos_de_Ordenamient.MainQuick
```

```bash
java -cp out Metodos_de_Ordenamient.MainShell
```

Ambos programas utilizan un arreglo de ejemplo y muestran el arreglo original y el resultado ordenado en la terminal.
